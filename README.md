
# Data Analytics Project

## Overview

An end-to-end data analytics project using **Python, PostgreSQL, SQL, and Power BI** to analyze data and generate actionable insights.

**Workflow:**
`Python → EDA → PostgreSQL → SQL Analysis → Power BI`

## Dataset

The dataset was loaded and explored using Python. EDA was performed to understand data types, missing values, duplicates, distributions, and key patterns.

## Tools

* **Python & Pandas** – Data loading and EDA
* **PostgreSQL** – Data storage and querying
* **SQL** – Data analysis
* **Power BI** – Dashboard and visualization

## Steps

1. Loaded and explored the dataset using Python.
2. Performed EDA and data cleaning.
3. Stored the data in PostgreSQL.
4. Wrote SQL queries to analyze key metrics and trends.
5. Built an interactive Power BI dashboard.

## Dashboard

The Power BI dashboard presents key KPIs, trends, comparisons, and interactive filters.

![Power BI Dashboard](images/dashboard.png)

## Results

* Identified key trends and patterns in the data.
* Generated analytical insights using SQL.
* Built an interactive dashboard for clear data-driven analysis.

## Run

```bash
pip install -r requirements.txt
```

Open the Jupyter Notebook to run the Python analysis, execute the SQL queries in PostgreSQL, and open the `.pbix` file in Power BI Desktop.
